Bug Bounty Agent

A local, human-in-the-loop bug-bounty agent running against a local LLM. A LangGraph state machine over ~65 tool wrappers automates recon, assessment and reporting — while every risky action is gated behind explicit human approval.

Python LangGraph Ollama HITL Safety
  • → Sequence-aware business-logic & auth-flow reasoning, not just fuzzing
  • → ROI prioritiser ranks targets by expected payout before spending scan budget
  • → Fail-closed risk model with batched approvals, never LLM-judged
